# HALCON-TORO

משחק אסטרטגיה לשני שחקנים. Web MVP — משחק מקומי על אותו מכשיר.

## הרצה

```bash
npm install
npm test
npm run dev
```

פתחו http://localhost:3000

- **הדרכה** — `/play/tutorial`
- **מול מחשב** — `/play/ai`
- **מקומי לשניים** — `/play/local`

## מבנה

- `packages/engine` — מנוע חוקים טהור + בדיקות R-01…R-14
- `apps/web` — Next.js UI
